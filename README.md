# ⚙️ Physical Engine

> *A tiny physics sandbox where gravity is optional, walls are unforgiving, and every throw tells a story.*

**Physical Engine** — небольшой интерактивный физический симулятор на Python с использованием Pygame. Здесь можно управлять шаром, бросать его, наблюдать за отскоками и экспериментировать с гравитацией.

Никакой магии. Только скорость, ускорение и немного физики. 🪐

## ✨ Возможности

- 🟢 **Gravity toggle** — включай и выключай гравитацию одним нажатием.
- 🖱️ **Drag & throw** — хватай шар мышкой, перемещай его и отпускай, чтобы запустить в полёт.
- 🧱 **Wall collisions** — шар отскакивает от стен, пола и потолка.
- 🏀 **Realistic-ish bouncing** — отскоки с потерей энергии благодаря коэффициенту упругости.
- 📐 **Velocity tracking** — скорость шара вычисляется в процессе движения и выводится в консоль.
- 🎮 **Real-time simulation** — физика и отрисовка работают в игровом цикле с целевой частотой 60 FPS.

## 🎮 Управление

| Действие | Что происходит |
|---|---|
| 🖱️ Зажать левую кнопку на шаре | Взять шар |
| ↔️ Перемещать мышь | Перемещать шар |
| 🖐️ Отпустить кнопку | Запустить шар в полёт |
| 🟢 Нажать `GRAVITY` | Включить гравитацию |
| ⚫ Нажать `GRAVITY` ещё раз | Выключить гравитацию |
| ❌ Закрыть окно | Завершить симуляцию |

## 🔬 Физика

В симуляции используются несколько основных параметров:

```python
g = 980          # Ускорение свободного падения
bounce = 0.75    # Коэффициент упругости
FPS = 60         # Целевая частота кадров
circle_rad = 50  # Радиус шара
```

**Как это работает?**

- **Гравитация** изменяет вертикальную скорость шара с течением времени.
- **Движение** рассчитывается через скорость и временной шаг между кадрами.
- **Столкновения** со стенами, полом и потолком меняют направление соответствующей составляющей скорости.
- **Потеря энергии** при отскоках моделируется коэффициентом `bounce`.
- **Затухание** останавливает очень медленные вертикальные отскоки у пола.

При коэффициенте упругости `0.75` шар теряет часть энергии при каждом отскоке. Поэтому рано или поздно его прыжки практически прекращаются.
